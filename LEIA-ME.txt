COMO PUBLICAR E INSTALAR
1. Publique todos os arquivos desta pasta em um serviço de hospedagem estática com HTTPS.
   Exemplos: GitHub Pages, Netlify ou Cloudflare Pages.
2. Abra o endereço publicado no Safari do iPhone.
3. Toque em Compartilhar > Adicionar à Tela de Início.
4. Abra pelo ícone criado. Depois da primeira carga, os arquivos principais ficam em cache para uso offline.

ARMAZENAMENTO E BACKUP
- Os lançamentos ficam no armazenamento local do navegador (localStorage).
- Use Configurações > Exportar backup (.json) regularmente.
- Para restaurar: Configurações > Importar backup.
- CSV exporta os lançamentos para planilha.
- Limpar dados do site/navegador pode apagar os dados locais. O backup JSON é importante.
